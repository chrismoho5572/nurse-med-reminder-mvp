# Nurse Medication Reminder MVP

ต้นแบบเว็บแอพสำหรับช่วยพยาบาลเตือนรายการให้ยาในแต่ละเตียงระหว่างเวร โดยเริ่มจากการใช้งานส่วนตัวบนมือถือหรือคอมพิวเตอร์ทั่วไป

> สถานะโปรเจกต์: Prototype / MVP สำหรับรับ feedback เท่านั้น

## ทำอะไรได้บ้าง

- เพิ่มเลขเตียงและรายการยา
- ระบุเวลา ขนาดยา วิธีให้ และหมายเหตุ
- ดูรายการที่ต้องให้ยาเรียงตามเวลา
- เห็นสถานะ `รอเวลา`, `ใกล้ถึงเวลา`, `เลยเวลา`, และ `ให้ยาแล้ว`
- กดบันทึกว่าให้ยาแล้ว
- ดูประวัติรายการที่ให้ยาแล้วระหว่างเวร
- ส่ง feedback จากหน้าเว็บ โดยเปิดเป็น GitHub Issue หรือคัดลอกข้อความไปส่งช่องทางอื่น
- ติดตั้งเป็น PWA บนมือถือได้ และใช้ system notification เมื่อ browser รองรับ
- ข้อมูลเก็บในเครื่องของผู้ใช้ผ่าน browser local storage

## วิธีลองใช้งาน

เปิดไฟล์ `index.html` ใน browser ได้ทันที หรือเปิดผ่าน GitHub Pages หลังจากนำ repo ขึ้น GitHub

### เปิด GitHub Pages

1. เข้า repository บน GitHub
2. ไปที่ `Settings`
3. เลือก `Pages`
4. ใน `Build and deployment` เลือก branch หลัก เช่น `main`
5. เลือก folder เป็น `/root`
6. กด `Save`

หลังจากนั้น GitHub จะสร้างลิงก์เว็บสำหรับทดลองใช้งาน

## การติดตั้งบนมือถือและแจ้งเตือน

### iPhone

1. เปิดเว็บด้วย Safari
2. กดปุ่ม Share
3. เลือก `Add to Home Screen`
4. เปิดเว็บจากไอคอนบน Home Screen
5. กด `เปิดแจ้งเตือน` ในแอพ

หมายเหตุ: iPhone ต้องใช้ iOS/iPadOS 16.4 ขึ้นไปสำหรับ web push/notification ใน web app และการแจ้งเตือนขึ้นอยู่กับ permission, silent mode, Focus mode และการตั้งค่าระบบของเครื่อง

### Android

1. เปิดเว็บด้วย Chrome
2. เลือก `Install app` หรือ `Add to Home screen`
3. เปิดเว็บจากไอคอนที่ติดตั้ง
4. กด `เปิดแจ้งเตือน`

### ข้อจำกัดของต้นแบบ

การแจ้งเตือนในรอบนี้ทำงานได้ดีที่สุดเมื่อเว็บแอพยังเปิดอยู่หรือยังทำงานอยู่ใน browser/PWA ถ้าปิดแอพทิ้ง ล็อกระบบจำกัด background หรือปิดสิทธิ์ notification ระบบอาจไม่เตือน การเตือนแบบรับประกันแม้แอพปิดสนิทควรทำด้วย backend push หรือ native mobile app ในเฟสถัดไป

## ข้อควรระวังสำคัญ

ต้นแบบนี้เป็นตัวช่วยเตือนส่วนตัว ไม่ใช่ระบบเวชระเบียน ไม่ใช่ระบบสั่งยา และไม่ใช่เครื่องมือทดแทนขั้นตอนตรวจสอบยาตามมาตรฐานของโรงพยาบาล

ห้ามใช้ข้อมูลที่ระบุตัวคนไข้ได้ เช่น:

- ชื่อหรือนามสกุล
- เลข HN
- เลขบัตรประชาชน
- เบอร์โทร
- ข้อมูลส่วนตัวอื่น ๆ

ช่วงทดสอบควรใช้ข้อมูลสมมติหรือเลขเตียงเท่านั้น

## แนวทางทดสอบกับผู้ใช้จริง

1. จำลองเวรหนึ่งรอบด้วยข้อมูลสมมติ 5-10 เตียง
2. ให้พยาบาลลองกรอกรายการยาเองเหมือนตอนรับเวร
3. ดูว่าการเพิ่มรายการใช้เวลานานเกินไปหรือไม่
4. ดูว่าหน้า “ตอนนี้” อ่านทันในสถานการณ์งานยุ่งหรือไม่
5. ถามว่าสี สถานะ และปุ่มกดชัดเจนพอหรือไม่
6. เก็บรายการสิ่งที่ควรเพิ่ม เช่น เลื่อนเวลา งดยา หรือเตือนซ้ำ

ผู้ทดสอบสามารถเปิดแท็บ `Feedback` ในหน้าเว็บเพื่อส่งข้อเสนอแนะเข้า GitHub Issues ได้โดยตรง หากไม่สะดวก login GitHub สามารถกดคัดลอกข้อความแล้วส่งให้ผู้พัฒนาแทนได้

## ไฟล์ในโปรเจกต์

- `index.html` - เว็บแอพต้นแบบแบบไฟล์เดียว
- `manifest.webmanifest` - ข้อมูลสำหรับติดตั้งเป็น PWA
- `sw.js` - service worker สำหรับ cache และจัดการ notification click
- `icons/icon.svg` - ไอคอนเว็บแอพ
- `Medication-Reminder-MVP.md` - เอกสารแนวคิด MVP และแผนทดสอบ
- `LICENSE` - เงื่อนไขการใช้งานโค้ด

## Roadmap เบื้องต้น

- เพิ่มสถานะ `เลื่อนเวลา`, `งดยา`, `รอประเมิน`
- เพิ่มตัวกรองตามเตียงหรือช่วงเวลา
- เพิ่ม export รายการสำหรับส่งเวร
- ปรับการกรอกข้อมูลให้เร็วขึ้นสำหรับมือถือ
- เพิ่มโหมดใช้งานหลายเวรโดยไม่ปนข้อมูลเดิม
